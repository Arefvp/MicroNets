# MicroNets

Other names: nets, meshes, cell meshes, cell filters, microNets, microMeshes, mesh filters

These files include designs, fabrication methods, and descriptions of applications of a plastic 2D or 3D net structure that can be used as a filter or a grid. Applications include electron microscopy (SEM, TEM, Cryo-EM) imaging grids, as well as capturing of cells and particles, such as circulating tumor cells, blood clots, and small particles.

Check out our microCodes platform here: https://github.com/Arefvp/MicroCodes microCodes are designed to facilitate navigation, identification, and image registration. MicroNets can be coupled with microCodes. Check out the MicroCodes GitHub and related papers for MicroCodes-embedded versions of MicroNets.
